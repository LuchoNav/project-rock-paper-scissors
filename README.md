# 💻 Odin Mini Game — Rock, Paper, Scissors


---

## 🇬🇧 English

Practice project developed as part of **The Odin Project** curriculum.

### Description

Classic **Rock, Paper, Scissors** console game developed with JavaScript.

### Technologies

- JavaScript
- HTML

### Learning Objectives

- Practice creating and using **functions**
- Work with **`for` loops**
- Practice using **`if/else` conditionals**
- Work with **variables and operators**
- Handle and process **user input**
- Generate **random choices** using `Math.random()`
- Practice program logic and **control flow**
---

## 🇪🇸 Español

Proyecto de práctica desarrollado como parte del currículo de **The Odin Project**.

### Descripción

Clásico juego de **piedra, papel o tijeras** por consola, desarrollado con JavaScript.

### Tecnologías

- JavaScript
- HTML

### Objetivos de aprendizaje

- Practicar la creación y uso de **funciones**
- Trabajar con **bucles `for`**
- Practicar el uso de **condicionales `if/else`**
- Trabajar con **variables y operadores**
- Obtener y procesar la **entrada del usuario**
- Generar elecciones **aleatorias** con `Math.random()`
- Practicar la lógica y el **flujo de un programa**
